# Data Source

This project uses the **Sleep Health and Lifestyle Dataset** by Laksika Tharmalingam, obtained from Kaggle.

- Source: Kaggle
- Dataset: Sleep Health and Lifestyle Dataset
- Rows: 374
- Columns: 13

The dataset includes variables related to sleep duration, sleep quality, physical activity, stress level, BMI category, occupation, age, and sleep disorders.

Dataset source: https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset

The original dataset is not included in this repository. Please obtain the dataset directly from the original source.
